## Sobre o projeto

A Jujuba’s Dev é uma empresa fictícia criada no contexto de um Trabalho de Conclusão de Curso em Desenvolvimento de Sistemas. Sua proposta é aproximar pequenos negócios, empreendedores e startups da tecnologia, combinando identidade visual e desenvolvimento de software.

Este portfólio apresenta a marca e duas soluções: **Kiora**, voltada à gastronomia, e **TechStart**, voltada à organização de eventos. A ararajuba inspira a identidade brasileira, as cores e o movimento da interface.

> `if(you need) { we code }`

## Soluções apresentadas

### Kiora

Um ecossistema digital para a experiência de um restaurante: sistema web de delivery e proposta de aplicativo para reservas, criação de pedidos e gerenciamento de mesas pela equipe.

[Conhecer o Kiora](https://kiorarestaurante.onrender.com)

### TechStart

Uma landing page de apresentação da startup e um sistema desktop para cadastrar, consultar, editar e excluir eventos.

[Conhecer a TechStart](https://ghostriley115.github.io/techstart-landing-page/)

## Experiência do portfólio

- Identidade visual original, com logos e materiais das marcas.
- Temas claro e escuro, com preferência persistente e integração ao tema do dispositivo.
- Layout responsivo para computadores, tablets e celulares.
- Apresentação dos projetos com abas, capturas e mockups.
- Galeria com filtros por marca e visualização ampliada.
- Animações que respeitam a preferência por movimento reduzido.
- Navegação por teclado, rótulos acessíveis e textos alternativos nas imagens.

## Tecnologias

**React 19 · Vite 7 · JavaScript · CSS · Lucide React · GitHub Actions · GitHub Pages**

O portfólio é uma aplicação estática. Os sistemas de delivery, reservas e gestão de eventos são projetos apresentados por ele, não funcionalidades executadas dentro desta aplicação.

## Contexto acadêmico

Jujuba’s Dev e Kiora são marcas fictícias desenvolvidas para fins acadêmicos. Os materiais de ambientação do Kiora são ilustrativos e identificados como tal. A apresentação da TechStart utiliza uma captura da landing page e um mockup de seu sistema desktop.

O projeto explora a relação entre desenvolvimento de sistemas, experiência do usuário e construção de identidade visual.
